## Description

> Autonomy is only sellable when its limits are technical, not written in a policy document. I run a fleet of AI developer agents at a regulated legal-tech platform: 291 bot-authored pull requests merged into the test tooling that guards it in three and a half months, 113 tickets tested automatically, 61 new end-to-end tests created, and every one of those merges approved by a person. The mechanism that makes this acceptable is not governance prose: a pre-tool hook hard-blocks every merge form, sweeps run dry against live data first, switches are reviewed git commits rather than container settings, and anything undecidable goes to a named human. The talk covers the three-plane model, the four-layer release ladder, the reporting contract that stops a bot announcing work it cannot perform, and four failures with the guards they produced. Contrarian closing: the interesting number is not 291 pull requests, it is the zero.
